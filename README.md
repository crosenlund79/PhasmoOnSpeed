# SPECTRAL RUN

A fast, single-player Gothic Noir supernatural investigation speedrunner for
**Godot 4.3** (GL Compatibility renderer, strictly 2D, directly overhead).

Pick one of five handcrafted houses, find out what is haunting it, prepare the
right countermeasure and vanquish it — ideally in three to five minutes.
Evidence goes into your journal automatically. You may attempt to vanquish at
any time, even blind… but the house notices recklessness.

The player believes they are investigating ghosts. Sometimes they are
dangerously mistaken.

## Running

1. Install Godot **4.3** (standard build).
2. Open `project.godot` in the editor (this imports the art and audio) and press
   Play, or run `godot --path .` from the repository root.

## Controls

| Input | Action |
|---|---|
| WASD / arrow keys | Move |
| Shift | Sprint (limited stamina) |
| Mouse | Aim / facing |
| F | Flashlight on/off |
| 1 – 9 | Select base equipment |
| Q / mouse wheel | Cycle items (Q jumps to found resources) |
| Left click | Use the equipped item (ask, place, pour, splash, strike; hold for the hand mirror) |
| E | Interact: pick up, retrieve placed items; **hold** to melt silver or light sigil candles |
| Tab | Choose the ghost you suspect (just a choice, never an attempt) |
| V (hold) | Perform the banishing rite |
| R (hold) | Restart the run immediately |
| H | Controls overlay |
| Esc / P | Pause |
| F11 | Fullscreen |

## How a run works

* **Equipment** (all available at once): flashlight, EMF reader, thermometer, UV
  flashlight, Spirit Box, Ghost Writing Book, orb camera, salt, crucifix, holy
  water. House **resources** (garlic, wooden stake, silverware, hand mirror,
  iron nails) are found in logical rooms and join the hotbar when picked up.
* **Journal** (right edge): timer, wounds, dread, discovered evidence as compact
  records — icon, name, elapsed time, room — and a one-line list of the
  conventional evidence not yet confirmed. Hidden evidence types never appear
  until you actually discover one.
* **Entities**: two conventional ghosts (the Shade, the Poltergeist), and three
  that are *not* ghosts and laugh at ghost equipment. A fourth, worse thing
  answers repeated recklessness.
* **Danger** rises with time and with what you do. Hunts are announced
  (flickering lights, a shriek, a red vignette); break line of sight to survive.
  The first hit wounds you (brief protection follows); the second is fatal.
* **Results**: VANQUISHED! or PERISHED!, score with a full breakdown, records,
  ranking against fictional legendary hunters, and a 4× replay of your actual
  run looping behind the panel.

## Project layout

```
assets/provisional/   original provisional artwork (generated, replaceable)
assets/creator/       drop creator artwork here — overrides provisional by path
assets/audio/         procedural sound effects and music
assets/fonts/         IM Fell (SIL Open Font License)
data/houses/          five house definitions (JSON, generated by tools/houses)

scripts/autoload/     Art, Sfx, SaveData, Online, Game (screen flow)
scripts/core/         scoring, journal model, rankings, controls

scripts/game/         Run controller, player, creature, occupants, phenomena, equipment, replay recorder

scripts/ui/           menus, HUD/journal, results, rankings, DEV statistics

tests/                headless test suite and balance bot
tools/                art/audio generators, house authoring tool, screenshot capture
```

## Replacing artwork

See `docs/ASSET_MANIFEST.md`. Put a PNG with the same relative path into
`assets/creator/` (e.g. `assets/creator/tokens/werewolf.png`), open the project
once in the editor so it is imported, and the game uses it instead of the
provisional piece. Gameplay code never references artwork directly.

## Editing houses

Houses are authored in `tools/houses/build_houses.py` as room rectangles, door
cells and furniture, then exported to `data/houses/*.json`:

```bash
python3 tools/houses/build_houses.py --validate
python3 tools/houses/build_houses.py --preview /tmp/house_previews
```

Validation checks furniture placement, blocked doors, full reachability and
dead-end rooms. Every room has a stable `id` and a readable `name`; evidence
records keep the room where the evidence actually occurred.
